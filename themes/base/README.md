# Base

Not a finished theme: a starting point for building your own. `theme.scss` adds rounded
corners and a rainbow highlight for the selected effect, and pulls in a colour set via
`@import` (currently the empty partial `_theme00.scss`).

## Files

- [`theme.scss`](theme.scss) / [`theme.css`](theme.css) - the base frame
- [`_theme00.scss`](_theme00.scss) - empty colour set to start from
